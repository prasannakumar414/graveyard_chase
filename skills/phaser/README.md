# Phaser skills

Source: [official Phaser skills](https://github.com/phaserjs/phaser/tree/master/skills), branch `master`. Retrieved on 2026-11-05 for this project's Phaser 4 setup.

These are project-local guides loaded through the root `AGENTS.md`. They are not installed globally. Read only the guides relevant to the current task. Verify version-sensitive APIs against the installed Phaser package.

The 27 vendored guides were retrieved through the web reader after the installer failed because terminal DNS was unavailable. The DataManager entry links to the official guide because its raw Markdown could not be retrieved with formatting preserved. Relative links between skill directories retain their upstream layout.
